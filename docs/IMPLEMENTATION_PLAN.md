### ✔️ المهمة 1/35 — هيكلة Monorepo

**ماذا نُفّذ:** بنية pnpm workspace + Turborepo بـ4 تطبيقات (`public-site`, `dashboard`, `console`, `api`) وحزمة `packages/shared` (أنواع TypeScript مطابقة لكل جدول في نموذج البيانات + Zod schemas للتحقق من صحة الإدخال: الجوال/OTP/كلمة المرور، التسجيل حسب نوع الحساب، العقارات والبحث، الـLeads). إعدادات موحّدة (TypeScript صارم، ESLint، Prettier) على مستوى الجذر ليتبعها الجميع.

**التحقق (لم أكتفِ بالكتابة، شغّلت الأدوات فعليًا):** `pnpm install` ✅، `pnpm typecheck` ✅ (5 حزم)، `pnpm build` ✅ (الأربع تطبيقات تُبنى بنجاح)، `pnpm lint` ✅ بلا أخطاء.

**مراجعة الأمان:** لا كود وظيفي بعد (مجرد هياكل فارغة) — لا سطح هجوم حاليًا. النقطة الوحيدة ذات الصلة: أضفت `.env.example` لكل تطبيق يوضح أي متغيرات بيئة مطلوبة **بدون قيم حقيقية**، وتأكدت أن `.gitignore` يستثني `.env*` فعليًا حتى لا يُرفع مفتاح بالخطأ لاحقًا.

**ما حُذف/لم يُبنَ:** لا شيء حُذف (بداية جديدة)، لكن لم أُنشئ `apps/console/.next` وغيرها من ملفات البناء المؤقتة في الكود المرفوع (مُستبعدة عبر `.gitignore`، تحقّقت من ذلك قبل الرفع).

**SQL مطلوب في Supabase الآن:** لا شيء بعد — قادم في المهمة 2/35.

**مهام Railway مطلوبة منك الآن:** لا شيء بعد. سأعطيك دليل نشر كامل خطوة بخطوة في المهمة 35/35 بعد اكتمال الكود، حتى لا تُنشئ خدمات فارغة الآن.

**خطوة عملية واحدة لك إن أردت تجربة الكود محليًا:** ثبّت Node.js 20+ وpnpm، ثم من جذر المشروع: `pnpm install` ثم `pnpm dev` (يشغّل كل التطبيقات الأربعة معًا). ليست إلزامية الآن — يمكن الانتظار حتى تكتمل ميزات فعلية لتجربتها.
